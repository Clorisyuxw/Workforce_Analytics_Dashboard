# Workforce Analytics Dashboard

## Project Overview

This project demonstrates an end-to-end workforce analytics solution built using Snowflake, SQL, and Power BI.

The objective was to simulate a real-world HR analytics environment by generating employee data, loading it into a cloud data warehouse, performing SQL-based analysis, and developing interactive dashboards to support workforce reporting and decision-making.

## Tools Used

* Snowflake
* SQL
* Power BI
* Python (Faker)

## Dataset

A synthetic employee dataset containing 200 employee records was generated using Python Faker. The dataset included:

* Employee information
* Department data
* Job titles
* Employment status
* Performance ratings
* Demographic information

## Business Questions

The dashboard was designed to answer key workforce questions:

* How many employees are currently active?
* What is the employee turnover rate?
* Which departments have the largest workforce?
* What are the most common job roles?
* What is the gender distribution across the workforce?
* How are employees performing across performance categories?

## Dashboard Features

### Workforce KPIs

* Total Employees
* Active Employees
* Terminated Employees
* Turnover Rate
* High Performers

### Workforce Analysis

* Department Distribution
* Job Title Distribution
* Gender Distribution
* Performance Distribution

## Key Findings

* Total Employees: 200
* Active Employees: 120
* Turnover Rate: 40%
* Production Department represented the largest workforce segment.
* Most employees achieved "Fully Meets" performance ratings.
* High performers accounted for approximately 10% of the workforce.
